# CycloneAI Rules

1. Separate member ownership.
2. Stable API contracts.
3. Dockerize every service.
4. Use Docker service names for internal communication.
5. No credentials in Git.
6. No huge datasets in Git.
7. UTC timestamps.
8. Validate coordinates.
9. Avoid temporal/data leakage.
10. Version models and datasets.
11. Do not hardcode fake predictions.
12. Distinguish observation from prediction.
13. Test every major module.
14. Update documentation after architecture/schema changes.
15. The system is a prototype decision-support tool, not an official warning service.
