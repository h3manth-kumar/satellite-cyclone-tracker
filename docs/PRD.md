# CycloneAI PRD

## Vision
An AI-powered research/decision-support prototype for identifying, classifying, and predicting tropical cyclone patterns from multi-source satellite and meteorological data.

## Users
- Meteorologists
- Disaster management authorities
- Researchers
- Emergency response teams
- Government stakeholders

## MVP
- Cyclone detection
- Cyclone classification
- Track prediction
- Intensity prediction where supported
- Satellite visualization
- Interactive map
- Confidence/uncertainty
- Explainability
- Dockerized deployment

## Team Ownership
- Member 1: detection/classification
- Member 2: data/forecasting
- Member 3: application/integration

## Success Metrics
Detection: precision, recall, F1
Classification: accuracy, macro F1
Track: Haversine/mean track error in km
Intensity: MAE/RMSE
System: API reliability, inference time, successful end-to-end workflow

## Safety/Product Boundary
The prototype is not an official weather-warning system and must not replace authorized meteorological forecasts.
